# Linux 磁盘管理

- 实验 ID：`linux-disk-management`
- 难度：简单-适中
- 适用场景：高校课程实训、课后上机实验、基础运维实操练习
- 镜像：`linux-ai-exp:linux-disk-management-v1`

## 实验目标

认识磁盘容量、目录占用、块设备信息和基础归档整理操作。

## 实验环境

- 系统：openEuler 容器环境
- 用户：student
- 工作目录：/home/student
- 所有操作均在实验容器内完成，避免修改宿主机环境。

## 实验步骤

### 步骤 1：查看文件系统容量

**目标：** 了解挂载点容量信息。

**操作说明：** 执行 df -h，观察 Size、Used、Avail。

参考命令：

```bash
df -h
```

**完成标准：** 命令成功输出文件系统容量。

### 步骤 2：查看目录占用

**目标：** 统计实验目录大小。

**操作说明：** 执行 du -sh disk。

参考命令：

```bash
du -sh disk
```

**完成标准：** 输出 disk 目录占用。

### 步骤 3：查看块设备

**目标：** 认识 lsblk 输出结构。

**操作说明：** 执行 lsblk，观察 NAME、SIZE、TYPE。

参考命令：

```bash
lsblk
```

**完成标准：** 命令成功输出块设备表。

### 步骤 4：查找临时文件

**目标：** 定位后缀为 tmp 的文件。

**操作说明：** 使用 find 查找临时文件。

参考命令：

```bash
find disk -name "*.tmp"
```

**完成标准：** 输出 c.tmp 路径。

### 步骤 5：移动日志归档

**目标：** 把日志文件整理到归档目录。

**操作说明：** 移动 .log 文件到 archive。

参考命令：

```bash
mv disk/work/*.log disk/archive/
```

**完成标准：** archive 中存在 a.log 和 b.log。

### 步骤 6：记录磁盘检查

**目标：** 形成磁盘巡检摘要。

**操作说明：** 写入磁盘检查摘要文件。

参考命令：

```bash
echo "disk usage checked" > disk/disk-summary.txt
```

**完成标准：** disk-summary.txt 包含 usage。

## 学习记录建议

- 每完成一步，记录关键命令、观察到的输出和自己的判断。
- 遇到报错时先阅读错误信息，再检查路径、权限、命令拼写和文件是否存在。
- 实验结束后可重新查看生成的记录文件，复盘自己完成了哪些操作。
