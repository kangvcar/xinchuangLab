# 正则表达式认知

- 实验 ID：`regex-awareness`
- 难度：简单-适中
- 适用场景：高校课程实训、课后上机实验、基础运维实操练习
- 镜像：`linux-ai-exp:regex-awareness-v1`

## 实验目标

认识正则表达式的普通字符、锚点、字符类、数量词和 grep -E 基础用法。

## 实验环境

- 系统：openEuler 容器环境
- 用户：student
- 工作目录：/home/student
- 所有操作均在实验容器内完成，避免修改宿主机环境。

## 实验步骤

### 步骤 1：普通关键词匹配

**目标：** 用 grep 匹配固定文本。

**操作说明：** 查找 alice 所在行。

参考命令：

```bash
grep alice regex/accounts.txt
```

**完成标准：** 输出 alice 行。

### 步骤 2：行首匹配

**目标：** 使用 ^ 匹配行首。

**操作说明：** 查找以 b 开头的账号。

参考命令：

```bash
grep "^b" regex/accounts.txt
```

**完成标准：** 输出 bob 行。

### 步骤 3：行尾匹配

**目标：** 使用 $ 匹配行尾。

**操作说明：** 查找以 tcp 结尾的服务。

参考命令：

```bash
grep "tcp$" regex/services.txt
```

**完成标准：** 输出 http、ssh、mysql 等行。

### 步骤 4：字符类匹配

**目标：** 用字符类匹配多个候选字符。

**操作说明：** 查找以 a 或 c 开头的账号。

参考命令：

```bash
grep "^[ac]" regex/accounts.txt
```

**完成标准：** 输出 alice 和 carol。

### 步骤 5：扩展正则数量词

**目标：** 用 grep -E 匹配数字长度。

**操作说明：** 查找包含四位数字的账号行。

参考命令：

```bash
grep -E "[0-9]{4}" regex/accounts.txt
```

**完成标准：** 输出 UID 为 1000、1001、2001 的行。

### 步骤 6：匹配端口协议

**目标：** 组合数字和协议进行匹配。

**操作说明：** 筛选 TCP 服务行。

参考命令：

```bash
grep -E "^[a-z]+ [0-9]+/tcp$" regex/services.txt
```

**完成标准：** 输出 tcp 服务记录。

### 步骤 7：保存匹配结果

**目标：** 把正则匹配结果写入文件。

**操作说明：** 保存普通用户 UID 匹配结果。

参考命令：

```bash
grep -E "[0-9]{4}" regex/accounts.txt > regex/output/normal-users.txt
```

**完成标准：** normal-users.txt 存在并包含 alice。
