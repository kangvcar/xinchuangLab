# Linux 系统认知

- 实验 ID：`linux-system-awareness`
- 难度：简单-适中
- 适用场景：高校课程实训、课后上机实验、基础运维实操练习
- 镜像：`linux-ai-exp:linux-system-awareness-v1`

## 实验目标

认识 Linux 系统环境、当前用户、目录位置、基础资源信息和系统版本信息。

## 实验环境

- 系统：openEuler 容器环境
- 用户：student
- 工作目录：/home/student
- 所有操作均在实验容器内完成，避免修改宿主机环境。

## 实验步骤

### 步骤 1：确认当前位置

**目标：** 确认登录后所在目录。

**操作说明：** 执行 pwd，观察当前工作目录。

参考命令：

```bash
pwd
```

**完成标准：** 终端输出一个绝对路径。

### 步骤 2：查看系统版本

**目标：** 了解系统发行版信息。

**操作说明：** 执行 cat /etc/os-release，找到 NAME 和 VERSION 字段。

参考命令：

```bash
cat /etc/os-release
```

**完成标准：** 能够看到 openEuler 或基础镜像版本信息。

### 步骤 3：查看内核信息

**目标：** 认识内核和架构信息。

**操作说明：** 执行 uname -a，观察 Linux 内核、主机名和架构。

参考命令：

```bash
uname -a
```

**完成标准：** 命令成功输出内核信息。

### 步骤 4：识别当前用户

**目标：** 确认当前终端使用的用户身份。

**操作说明：** 执行 whoami 和 id，观察用户名、UID、GID。

参考命令：

```bash
whoami
id
```

**完成标准：** 能看到 student 用户和对应 UID/GID。

### 步骤 5：查看资源概况

**目标：** 观察磁盘与内存基本状态。

**操作说明：** 执行 df -h 和 free -h，识别容量、已用和可用列。

参考命令：

```bash
df -h
free -h
```

**完成标准：** 能读出磁盘空间和内存容量。

### 步骤 6：记录系统摘要

**目标：** 把观察结果写入实验摘要文件。

**操作说明：** 创建 reports/system-summary.txt，写入本次系统认知摘要。

参考命令：

```bash
echo "system checked" > reports/system-summary.txt
```

**完成标准：** reports/system-summary.txt 文件存在并包含内容。

## 学习记录建议

- 每完成一步，记录关键命令、观察到的输出和自己的判断。
- 遇到报错时先阅读错误信息，再检查路径、权限、命令拼写和文件是否存在。
- 实验结束后可重新查看生成的记录文件，复盘自己完成了哪些操作。
